Subject: Big Chief electronic monthly settlement

Big Chief’s request can be accommodated through the existing national-accounts settlement process, provided its monthly submission includes the required ticket and account identifiers and balances to its single payment.

Big Chief should submit a monthly accounts-payable extract containing the parent number, outlet number, ticket number, ticket amount, and delivery date. If the parent and outlet numbers are not initially available, we can provide them from the customer master file for inclusion in subsequent submissions.

Big Chief will send the file to Data Processing in the format accepted by the national-accounts cash-receipt system and send a cheque, with a detailed listing, to the lockbox. Finance will balance the file under the prescribed procedure; the cheque total and file detail must net to zero.

After balancing, the file will run through the national-accounts system, match ticket numbers against statement history, and produce the relevant billing records.
