Subject: Big Chief Account 8306 — Electronic Settlement Request

Big Chief's request to submit delivery-ticket data electronically and settle it through one monthly prepaid payment is workable, provided three requirements are met.

1. **The file must carry five data elements per ticket.** Each record needs the parent number, outlet number, ticket number, ticket amount, and delivery date. If Big Chief cannot supply the parent and outlet numbers itself, we can populate them from our customer master file for later submissions.

2. **Big Chief must build the extraction and route the file and payment correctly.** Big Chief will extract the data from its accounts-payable file into the format our national-accounts cash-receipt system accepts, send that file to Data Processing, and send a cheque with a detailed listing to the lockbox. We will balance the file per our standard procedure, and the cheque total must net to zero against the file detail.

3. **Once balanced, the file will process through our existing system.** It will run through national-accounts, match ticket numbers against statement history, and generate the corresponding billing records.
