**Big Chief's request to settle electronically with one prepaid monthly payment can be accommodated within our existing national-accounts process.** Three things make it work.

**1. Big Chief can supply the data we require.** Any external account file must carry the parent number, outlet number, ticket number, ticket amount, and delivery date. Big Chief will write an extraction program against its accounts-payable file, producing a file in the format our national-accounts cash-receipt system already accepts. If Big Chief cannot provide the parent and outlet numbers, we can supply them from the customer master file for inclusion in later submissions.

**2. The submission can be balanced before it is applied.** Big Chief sends the file to Data Processing and its cheque, with a detailed listing, to the lockbox. We balance the file under the prescribed procedure; the cheque total and the file detail must net to zero.

**3. The balanced file processes through the existing system.** It runs through the national-accounts system, matches ticket numbers against statement history, and produces the relevant billing records.
