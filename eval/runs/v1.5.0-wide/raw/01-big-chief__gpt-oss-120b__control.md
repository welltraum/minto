**Recommendation**  
Approve Big Chief’s request to submit delivery‑ticket data electronically and settle the account with a single prepaid monthly payment, provided the file meets our data‑format requirements and the balancing procedure is followed.

**Key Findings**

1. **File content requirements**  
   *Every external file must contain:*  
   – Parent (account) number  
   – Outlet number  
   – Ticket number  
   – Ticket amount  
   – Delivery date  
   If Big Chief cannot supply the parent or outlet numbers, we can populate them from the customer master file before processing.

2. **Extraction, transmission, and payment**  
   *Big Chief will:*  
   – Build an extraction program that produces a file in the format accepted by our national‑accounts cash‑receipt system.  
   – Send the file to Data Processing and forward the accompanying cheque, together with a detailed listing, to the lockbox.  
   *Finance will:*  
   – Balance the file against the cheque; the total of the cheque must equal the sum of the file detail before the file proceeds.

3. **Processing and billing**  
   Once the file is balanced, it will run through the national‑accounts system, where ticket numbers are matched against statement history and the appropriate billing records are generated.

**Conclusion**  
The proposed monthly electronic settlement conforms to our existing settlement workflow. With the stipulated data elements and the balancing check in place, the process can be implemented without additional operational changes.
