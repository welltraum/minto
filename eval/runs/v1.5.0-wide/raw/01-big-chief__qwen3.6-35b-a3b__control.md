**Subject:** Big Chief Electronic Settlement Proposal  

Finance has reviewed Big Chief’s request to replace individual ticket settlements with a monthly electronic file and single prepaid payment. The proposed process is operationally feasible, provided the following three requirements are met:

**1. Data Specifications**  
The external file must contain the parent number, outlet number, ticket number, ticket amount, and delivery date. If Big Chief cannot provide the parent and outlet numbers, Finance will supply these identifiers from the customer master file for inclusion in all subsequent submissions.

**2. Submission and Reconciliation**  
Big Chief must develop an extraction program to generate a file compatible with our national-accounts cash-receipt system. Big Chief will transmit the file directly to Data Processing and mail the corresponding cheque with a detailed listing to the lockbox. Our team will balance the file according to standard procedures, ensuring the cheque total and file detail net to zero.

**3. System Processing**  
Following successful reconciliation, the monthly file will automatically route through the national-accounts system. It will match submitted ticket numbers against existing statement history and generate the appropriate billing records.
