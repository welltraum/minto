Subject: Big Chief monthly electronic settlement request

Big Chief, a major multi-outlet customer, has requested to replace individual delivery-ticket settlement with a monthly computer file and a single prepaid payment. Finance has reviewed the proposal and confirmed that we can accommodate this request, provided Big Chief adheres to our data and balancing requirements.

● **Data specifications:** The external file must include the parent number, outlet number, ticket number, ticket amount, and delivery date. If Big Chief cannot provide the parent and outlet numbers, we will supply these identifiers from the customer master file for subsequent submissions.

● **Submission and balancing:** Big Chief must build an extraction program to create a file compatible with our national-accounts cash-receipt system. Big Chief will send the file to Data Processing and remit the cheque with a detailed listing to the lockbox; the cheque total and file detail must net to zero under our prescribed balancing procedure.

● **System processing:** Once balanced, the monthly file will run through the national-accounts system to match ticket numbers against statement history and generate the relevant billing records.
