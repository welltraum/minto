We can accommodate Big Chief account 8306's request to settle delivery tickets through monthly electronic submission and a single prepaid payment. Implementation requires three coordinated steps.

**File Requirements and Preparation**
The monthly file must contain the parent number, outlet number, ticket number, ticket amount, and delivery date. We will source any missing parent or outlet numbers from our customer master file for inclusion in subsequent submissions. Big Chief will build an extraction program to format the data according to our national-accounts cash-receipt system specifications.

**Submission and Reconciliation Procedure**
Big Chief will transmit the formatted file to Data Processing and send its monthly cheque, along with a detailed listing, to the lockbox. We will balance the submission under our standard procedure to ensure the cheque total and file detail net to zero.

**System Processing and Billing**
Once balanced, the file will run through the national-accounts system, match ticket numbers against statement history, and generate the corresponding billing records.
