**To:** Robert Salton  
**From:** John Jackson  
**Subject:** Recommendation – Big Chief electronic monthly settlement  

**Recommendation**  
Approve Big Chief’s request to replace individual ticket settlements with a single prepaid monthly payment and an electronic delivery‑ticket file, provided the required identifiers are supplied and the balancing procedure is adhered to.

**Key considerations**

1. **Data requirements** – Every external file must contain the parent number, outlet number, ticket number, ticket amount, and delivery date. If Big Chief cannot provide the parent and outlet numbers, we can populate them from the customer master file for inclusion in subsequent submissions.

2. **Process flow** – Big Chief will develop an extraction program that produces a file in the format accepted by our national‑accounts cash‑receipt system. The file will be sent to Data Processing; the accompanying prepaid cheque and a detailed listing will be mailed to the lockbox. Finance will balance the file against the cheque total; the two must net to zero before proceeding.

3. **System integration** – Once balanced, the monthly file will run through the national‑accounts system, where ticket numbers are matched against statement history and the appropriate billing records are generated.  

**Conclusion**  
The proposed electronic settlement meets our procedural standards and can be implemented without changes to existing systems, subject to the data and balancing conditions outlined above.
