Subject: Big Chief request (account 8306)

Big Chief's request to submit delivery-ticket data electronically and settle by one prepaid monthly payment can be accommodated within our existing national-accounts systems, provided the file carries the required identifiers.

The process would work in three steps:

1. **Big Chief extracts and sends the data.** It will build an extraction program against its accounts-payable file, producing a file in the format our national-accounts cash-receipt system accepts. The file goes to Data Processing; the cheque, with a detailed listing, goes to the lockbox.

2. **We balance the file.** Under the prescribed procedure, the cheque total and the file detail must net to zero. The file must contain the parent number, outlet number, ticket number, ticket amount, and delivery date. If Big Chief cannot supply the parent and outlet numbers, we can provide them from the customer master file for inclusion in later submissions.

3. **The system processes the file.** Once balanced, the monthly file runs through the national-accounts system, matches ticket numbers against statement history, and produces the relevant billing records.
