Subject: Big Chief electronic monthly settlement request  

Big Chief’s request can be accommodated through the existing national-accounts settlement process, provided its monthly submission includes the required delivery-ticket identifiers and balances to its prepaid payment.

Big Chief should submit a monthly accounts-payable extract containing the parent number, outlet number, ticket number, ticket amount, and delivery date. If it cannot initially provide the parent and outlet numbers, we can supply them from the customer master file for inclusion in subsequent submissions.

Big Chief will send the file to Data Processing in the accepted national-accounts cash-receipt format and send its cheque, with a detailed listing, to the lockbox. Finance will balance the file under the prescribed procedure; the cheque total and file detail must net to zero.

After balancing, the file will be processed through the national-accounts system, matched against statement-history ticket numbers, and used to produce the relevant billing records.
