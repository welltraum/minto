Subject: Big Chief Proposal Review

Our review of Big Chief's request for monthly electronic settlement and single payment identifies the necessary data standards and the resulting operational workflow.

1. **Data Standards:** The submitted file must include the parent number, outlet number, ticket number, ticket amount, and delivery date. Should Big Chief be unable to provide the parent and outlet numbers, we will insert these identifiers from the customer master file in subsequent submissions.

2. **Reconciliation Workflow:** Big Chief will create an extraction program to produce a file compatible with our national-accounts cash-receipt system. Big Chief will transmit this file to Data Processing and deliver the associated cheque with a detailed listing to the lockbox. Finance will reconcile the file according to established procedures, verifying that the cheque total and file detail net to zero.

3. **Billing Processing:** Once reconciled, the monthly file will execute through the national-accounts system to cross-reference ticket numbers with statement history and generate the appropriate billing records.
