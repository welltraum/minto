We can implement Big Chief account 8306's request to settle delivery tickets electronically via one monthly prepaid payment, provided three requirements are met:

1. **Big Chief must supply a correctly formatted account file.** Each record must contain the parent number, outlet number, ticket number, ticket amount, and delivery date. If Big Chief cannot provide the parent and outlet numbers, we can supply them from our customer master file for later submissions.

2. **Big Chief must submit the file and payment in the prescribed way.** Big Chief will build an extraction program from its accounts-payable file, formatted for our national-accounts cash-receipt system, and send it to Data Processing. It will send its cheque with a detailed listing to the lockbox. We will balance the file under the prescribed procedure, and the cheque total must net to zero against the file detail.

3. **We will process the balanced file through our standard system.** Once balanced, the monthly file will run through the national-accounts system, match ticket numbers against statement history, and produce the relevant billing records.
