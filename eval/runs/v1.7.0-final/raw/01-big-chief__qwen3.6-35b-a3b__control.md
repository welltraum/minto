Subject: Big Chief Monthly Electronic Settlement Process

Big Chief's request to replace individual ticket settlement with a monthly computer file and single payment can be accommodated through the following defined workflow:

**1. File Data Requirements**
The external file must include the parent number, outlet number, ticket number, ticket amount, and delivery date. If Big Chief cannot provide the parent or outlet numbers, Finance will supply these identifiers from the customer master file for inclusion in later submissions.

**2. Submission and Reconciliation**
Big Chief will develop an extraction program to generate a file compatible with our national-accounts cash-receipt system. Big Chief will transmit the file to Data Processing and deliver the cheque with a detailed listing to the lockbox. We will reconcile the file using prescribed procedures, ensuring the cheque total and file detail net to zero.

**3. System Processing and Billing**
Once balanced, the file will run through the national-accounts system to match ticket numbers against statement history and produce the relevant billing records.
