Subject: Big Chief request (account 8306)

Big Chief's request to submit delivery-ticket data electronically and settle it with one prepaid monthly payment can be accommodated within our existing national-accounts cash-receipt system. Three things must hold.

1. **The file must carry the five required identifiers.** Any external account file must contain the parent number, outlet number, ticket number, ticket amount, and delivery date. If Big Chief cannot supply the parent and outlet numbers, we can provide them from the customer master file for inclusion in later submissions.

2. **The file and the payment must balance to zero.** Big Chief will write an extraction program against its accounts-payable file, producing a file in the format our national-accounts cash-receipt system accepts. Big Chief sends the file to Data Processing and the cheque, with a detailed listing, to the lockbox. We balance the file under the prescribed procedure; the cheque total and the file detail must net to zero.

3. **Processing then follows the standard path.** Once balanced, the monthly file runs through the national-accounts system, matches ticket numbers against statement history, and produces the relevant billing records.
