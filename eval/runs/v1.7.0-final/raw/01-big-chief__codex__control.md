Subject: Big Chief electronic monthly settlement request  

Big Chief’s request can be accommodated, provided its monthly file contains the required delivery-ticket identifiers and is balanced to its prepaid payment.

Big Chief should submit a monthly accounts-payable extract in the national-accounts cash-receipt format, containing the parent number, outlet number, ticket number, ticket amount, and delivery date. If it cannot supply the parent and outlet numbers initially, we can provide them from the customer master file for future submissions.

Big Chief should send the file to Data Processing and send its cheque, with a detailed listing, to the lockbox. Finance will balance the file under the prescribed procedure; the cheque total and file detail must net to zero.

After balancing, the file can be processed through the national-accounts system to match ticket numbers against statement history and produce the relevant billing records.
