Subject: Big Chief request — settlement by monthly file is workable

We can implement Big Chief account 8306's request to replace individual delivery-ticket settlement with one monthly computer file and a single prepaid payment, using our existing procedures.

1. The file Big Chief submits must carry parent number, outlet number, ticket number, ticket amount, and delivery date. If Big Chief cannot supply the parent and outlet numbers, we will add them from the customer master file for later submissions.

2. Big Chief will extract this data from its accounts-payable file in the format our national-accounts cash-receipt system already accepts, send the file to Data Processing, and send its cheque with a detailed listing to the lockbox. We will balance the file under our prescribed procedure, with the cheque total and file detail netting to zero.

3. Once balanced, the file will run through the national-accounts system, match ticket numbers against statement history, and produce the billing records.
