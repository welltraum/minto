Subject: Big Chief electronic monthly settlement request  

Big Chief’s request can be accommodated through the national-accounts settlement process, provided its monthly submission contains the required identifiers and balances to its prepaid payment.

- The electronic file must include the parent number, outlet number, ticket number, ticket amount, and delivery date. If Big Chief cannot initially provide the parent and outlet numbers, we can supply them from the customer master file for later submissions.

- Big Chief will extract the data from its accounts-payable file in the accepted national-accounts cash-receipt format, send the file to Data Processing, and send the cheque and detailed listing to the lockbox. Finance will balance the file under the prescribed procedure; the cheque total and file detail must net to zero.

- Once balanced, the monthly file will be processed through the national-accounts system, matched against statement history by ticket number, and used to produce the relevant billing records.
