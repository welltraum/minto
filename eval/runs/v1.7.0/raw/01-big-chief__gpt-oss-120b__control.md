**Subject:** Big Chief electronic settlement request – findings and next steps  

**Recommendation**  
We can accept Big Chief’s proposal to submit a single monthly electronic file and make one prepaid payment, provided the data‑format requirements are met and the balancing procedure is followed.

**Key conditions**

1. **Data identifiers** – Every external file must contain the parent number, outlet number, ticket number, ticket amount, and delivery date.  
   - If Big Chief cannot supply the parent and outlet numbers, we will add them from the customer‑master file before processing.

2. **File creation and transmission** – Big Chief will develop an extraction program that produces a file in the format used by our national‑accounts cash‑receipt system.  
   - The file will be sent to Data Processing; the accompanying cheque and a detailed listing will be mailed to the lockbox.  
   - Finance will balance the file against the cheque; the totals must net to zero before further processing.

3. **Processing and billing** – Once the file is balanced, it will run through the national‑accounts system, where ticket numbers are matched to statement history and the appropriate billing records are generated.

**Next steps**  
- Confirm with Big Chief that they can meet the identifier requirement or arrange for us to supply missing data.  
- Review the extraction program’s output format against our cash‑receipt specifications.  
- Establish the balancing checklist to ensure the file‑cheque total nets to zero before loading.  

Proceed with these actions to implement the monthly electronic settlement for Big Chief.
