Subject: Big Chief request (account 8306)

Big Chief's request to submit delivery-ticket data electronically and settle it with one prepaid monthly payment can be accommodated within our existing process. Three things make it work:

**1. The file can carry the data we need.** An external account file must contain the parent number, outlet number, ticket number, ticket amount, and delivery date. Big Chief will build an extraction program against its accounts-payable file, producing output in the format our national-accounts cash-receipt system accepts. If Big Chief cannot supply the parent and outlet numbers, we can provide them from the customer master file for use in later submissions.

**2. The payment can be balanced against the file.** Big Chief sends the file to Data Processing and its cheque, with a detailed listing, to the lockbox. We balance the file under the prescribed procedure; the cheque total and the file detail must net to zero.

**3. The balanced file processes through the existing system.** Once balanced, the monthly file runs through the national-accounts system, matches ticket numbers against statement history, and produces the relevant billing records.
