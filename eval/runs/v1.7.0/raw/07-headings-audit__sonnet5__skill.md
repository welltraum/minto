## Audit

**Text with markers**

```
▲ This memorandum describes how project teams identify and deliver significant
profit improvements. [⚠ topic label, not an answer]

It is organized in six sections:

    ○ Background                                    [⚠ not same-kind as siblings]
    ○ Principles of the project-team approach        [⚠ mixed kind]
    ○ Definition of project work                     [⚠ mixed kind]
    ○ Organization of the program                     [⚠ mixed kind]
    ○ Distinctive benefits and results                [⚠ mixed kind]
    ○ Conditions required for success                 [⚠ mixed kind]
[⇄ no stated ordering principle] [⊕ no visible question the six answer]
```

**Findings**

| Location | Violation | Fix |
|---|---|---|
| Opening sentence | States the topic ("describes how...") rather than an answer; no reader question is posed or answered | Replace with the actual answer — what the memo concludes about identifying/delivering profit improvements |
| Six-item list | Not same-kind: mixes a stage ("Background"), a concept ("Principles..."), a definition ("Definition of..."), a structure ("Organization..."), a payoff ("Distinctive benefits...") and a precondition ("Conditions...") — six different grammatical and logical kinds under one plural noun that doesn't exist | Reclassify into 3–4 same-kind groups (e.g., what it is / how it works / why it pays off / what it requires), dropping "Background" as intro material, not a section |
| Six-item list | No order type is named or evident — not time, not structure, not ranking | Choose one order (e.g., structure: definition → mechanics → organization; or induction: evidence → benefit → conditions) and sequence accordingly |
| "Background" as section 1 | This is Situation/Complication material, not a first-level branch — a buried intro | Move out of the list into a short SCQ-style opening; it isn't a "kind" of content the reader is choosing among |
| Whole opening | No Situation → Complication → Question visible before the six-way split; reader doesn't know what question these six sections jointly close | Supply one line of Situation + Complication, and a stated or implied question, before the list |

**Score:** Top 0 · Same-kind groups 0 · Order 0 · MECE 1 (no obvious duplication, but "Background" doesn't belong; coverage of the six sections themselves can't be judged without the body) · Display 1 (list is visible, but not a hierarchy)

**Total: 2/10 — not structured yet**

**Three fixes with the most leverage**

1. State the actual answer as the opening line, not a description of the memo's contents.
2. Recast "Background" out of the list and reclassify the remaining five into 3–4 same-kind groups.
3. Name and apply one order type to whatever groups remain.
