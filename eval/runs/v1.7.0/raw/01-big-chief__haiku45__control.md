**We can accommodate Big Chief's request to submit delivery-ticket data electronically and settle monthly through one prepaid payment.**

The implementation requires three coordinated steps:

1. **File Specifications**: The submission must include parent number, outlet number, ticket number, ticket amount, and delivery date. We can supply missing parent and outlet numbers from our customer master file.

2. **Monthly Settlement Process**: Big Chief will develop an extraction program to format its accounts-payable data per our national-accounts specifications. It sends the file to Data Processing and its cheque with supporting documentation to the lockbox. We balance the file per standard procedure, with the cheque and file detail netting to zero.

3. **Post-Settlement Processing**: Once balanced, the file will run through the national-accounts system to match ticket numbers against statement history and produce the necessary billing records.
