Subject: Big Chief request

We can implement Big Chief's request to replace individual ticket settlement with monthly electronic submission and one prepaid payment, provided the file meets our format and balancing requirements.

1. The account file must contain parent number, outlet number, ticket number, ticket amount, and delivery date; if Big Chief cannot supply the parent and outlet numbers, we will add them from our customer master file for later submissions.

2. Big Chief will extract this data from its accounts-payable file in the format used by our national-accounts cash-receipt system, send the file to Data Processing, and send its cheque with a detailed listing to the lockbox; we will balance the file under the prescribed procedure, with the cheque total and file detail netting to zero.

3. Once balanced, the file will run through the national-accounts system, where ticket numbers are matched against statement history to produce the billing records.
