Subject: Big Chief Request – Electronic Settlement Proposal

Big Chief's request to replace individual ticket settlement with a monthly computer file and single payment is addressed below. Our review defines the required data elements, the submission and reconciliation workflow, and the subsequent system processing.

**1. Data Requirements**
*   The external account file must contain the parent number, outlet number, ticket number, ticket amount, and delivery date.
*   If Big Chief cannot provide the parent and outlet numbers, Finance will supply these identifiers from the customer master file for inclusion in future submissions.

**2. Submission and Reconciliation Process**
*   Big Chief will develop an extraction program for its accounts-payable file, ensuring the output uses the format accepted by our national-accounts cash-receipt system.
*   Big Chief will transmit the file to Data Processing and deliver the corresponding cheque with a detailed listing to the lockbox.
*   Finance will balance the file according to the prescribed procedure, verifying that the cheque total and file detail net to zero.

**3. System Processing**
*   Upon successful balancing, the monthly file will be processed through the national-accounts system.
*   The system will match ticket numbers against statement history and generate the relevant billing records.
