Subject: Big Chief account 8306 monthly settlement  

Big Chief account 8306’s proposed replacement of individual ticket settlement with a monthly computer file and one prepaid payment would work through the national-accounts process if the file contains the required identifiers and balances to the payment.

- Required file data: The external account file must contain the parent number, outlet number, ticket number, ticket amount, and delivery date. If Big Chief cannot provide the parent and outlet numbers, we can supply them from the customer master file for later submissions.

- Submission and balancing: Big Chief will build an extraction program for its accounts-payable file in the format accepted by our national-accounts cash-receipt system. It will send the file to Data Processing and its cheque, with a detailed listing, to the lockbox. We will balance the file under the prescribed procedure; the cheque total and file detail must net to zero.

- Processing: Once balanced, the monthly file will run through the national-accounts system, match ticket numbers against statement history, and produce the relevant billing records.
