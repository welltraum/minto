Subject: Big Chief electronic monthly settlement request

Big Chief’s proposed monthly file and single prepaid payment can be processed through the existing national-accounts settlement procedure, provided the submission meets the required data and balancing controls.

- The monthly file must include parent number, outlet number, ticket number, ticket amount, and delivery date. If Big Chief cannot supply the parent and outlet numbers initially, we can provide them from the customer master file for later submissions.

- Big Chief will extract the data from its accounts-payable file in the format accepted by the national-accounts cash-receipt system, send the file to Data Processing, and send the cheque and detailed listing to the lockbox.

- Finance will balance the file under the prescribed procedure; the cheque total and file detail must net to zero. The balanced file will then run through the national-accounts system, match ticket numbers to statement history, and produce the relevant billing records.
