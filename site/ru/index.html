Нужен документ, по которому можно принять решение?

Разберитесь с аргументацией до того, как редактировать текст.

С Minto Codex и Claude Code сначала формулируют вопрос читателя, а затем редактируют текст. Готовый документ начинается с ответа и показывает, где аргументации не хватает.

Установить Minto Посмотреть пример до и после ↓

Установите Minto двумя командами.

Добавьте маркетплейс и установите плагин. После установки начните новую сессию.

Codex

CLI и desktop app
  1. 1 codex plugin marketplace add welltraum/minto
  2. 2 codex plugin add minto@minto

Затем вызовите $minto или просто опишите проблему с текстом.

Claude Code

CLI и desktop app
  1. 1 /plugin marketplace add welltraum/minto
  2. 2 /plugin install minto@minto

Затем вызовите /minto:minto или сформулируйте подходящую задачу.

В исходном отчёте рекомендация спрятана в последнем предложении.

В этом вымышленном примере факты остаются прежними, но решение стоит первым и показывает, как каждый факт его поддерживает.

Выберите режим под свою задачу.

Один исходник может дать четыре разных результата. Выбирайте режим по тому, что нужно понять или подготовить дальше.

intent

Определите задачу документа до того, как писать черновик.

Зафиксируйте читателя, решение и ответ, который можно подтвердить имеющимися фактами.

Вопрос читателя

Стоит ли запускать пилот онбординга в следующем месяце?

Ответ одним предложением Одобрите трёхнедельный пилот, чтобы проверить два подготовленных решения. Пробел в данных

До запуска определите целевой уровень активации.

audit

Посмотрите, где рвётся логика, не меняя исходный текст.

Minto оценивает структуру, называет дефект и предлагает исправление. Формулировки остаются прежними.

4,0Оценка структуры
  1. Проблема Рекомендация появляется последней.
  2. Проблема Факты и действия находятся на одном уровне.
  3. Исправление Начните с решения о пилоте, затем сгруппируйте факты.

write

Превратите заметки в документ, который начинается с вывода.

Режим подходит для письма или записки, а также для отчёта, one-pager и структуры презентации.
