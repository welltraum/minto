Install Minto in two commands.

Add the marketplace and install the plugin. Start a new session after installation.

Codex

CLI & desktop app
  1. 1 codex plugin marketplace add welltraum/minto
  2. 2 codex plugin add minto@minto

Then invoke $minto or describe the writing problem directly.

Claude Code

CLI & desktop app
  1. 1 /plugin marketplace add welltraum/minto
  2. 2 /plugin install minto@minto

Then invoke /minto:minto or let Claude route a matching request.
