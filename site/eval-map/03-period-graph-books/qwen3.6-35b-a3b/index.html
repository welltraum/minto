Defects Diagnosed

  • Missing Bottom-Line-Up-Front: Opens with historical context instead of a clear thesis, key finding, or recommendation.
  • Flat, Non-Hierarchical Structure: Procedural steps, diagnostic observations, and managerial assessments sit at the same level without subordinate relationships or summarizing statements.
  • Unstructured Grouping: Issues are presented narratively rather than categorized into logical, mutually exclusive groups (e.g., data handling, calculation integrity, accountability). Lacks a consistent ordering principle.
  • Redundancy Across Sections: The core critique—fragmented workflow, triple data entry, and unclear ownership—is repeated in “Issues” and “Overall assessment” without synthesis or elevation to a higher-level conclusion.
  • Mixed Content Types: Steps, problems, evaluations, and a request are blended without clear structural boundaries, violating Minto’s rule that each section must serve a single, distinct purpose.
  • Vague Call to Action: Closes with an open-ended question instead of a specific decision request, proposal, or defined next step aligned with the document’s purpose.

Required Changes

  • Place a single, clear top-level statement at the beginning that states the purpose, key finding, and recommended action.
  • Restructure into a strict top-down hierarchy: main conclusion → supporting categories (e.g., Root Causes, Operational Impact, Proposed Remediation) → detailed evidence beneath each category.
  • Group all issues logically using a consistent ordering principle (e.g., by process stage or functional domain), ensuring each group contains distinct, non-overlapping points that collectively cover the problem space.
  • Consolidate repetitive observations into single, well-defined categories; eliminate duplicate explanations of fragmentation and redundant data entry.
  • Replace the open-ended closing with a specific request for approval, decision, or next step that directly supports the top-level recommendation.
  • Ensure every section headline summarizes the content beneath it and maintain parallel grammatical structure throughout.

Subject: Period Graph Books

Since Period 5, Financial Analysis has been responsible for producing four
graph-presentation books previously handled by Corporate Planning. This memo
describes issues that appeared after the transfer.

Production

1. Gather data from divisional forms, internal documents, and telephone calls.
2. Calculate graph points manually or on the corporate computer, including
   rolling values for revenue, cost, and percentages.
3. Transcribe the points to input sheets. Analysts update the current period,
   then Color Graphics re-enters the points into its own database and generates
   the graphs.
4. Check the data and calculations.

Issues

The transfer inserted another person into an already fragmented process.
Divisional staff and three corporate departments participate, and the same
information may be entered into computer systems three times.

For one book, divisional data are loaded into a dedicated corporate program,
calculated, transferred to Color Graphics input sheets, entered again, and
returned for updates. Problems include inconsistent data between periods and
regions, incorrect variable-cost calculations, unexplained changes to points
that were previously correct, and prior-period data that must be re-entered.

Overall assessment

Most problems arise from a cumbersome fragmented process. No one controls the
data from beginning to end, responsibility is unclear, and errors can fall
between stages. The production process badly needs streamlining, both for each
book and for common calculations. The current team cannot manage the required
changes as well as ongoing production.

Could we discuss how best to proceed?
